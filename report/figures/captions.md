# Figure captions

All figures are regenerated by `make_figures.py` from `gpu_results/experiments/analysis/` (or `results/experiments/analysis/`, the same files, when `gpu_results/` is absent). Before drawing, the
script recomputes the numbers and checks them against `verification/CLAIMS.md`. Högskoleprovet results cover
the LÄS and MEK sections only (four options each). In the rotation tests every question is asked four times,
with the correct option moved to A, B, C and D in turn. "Editor 3's edit" is the edit trial_b50_k.

**Figure 1 (fig1_position_by_test).** How often unedited Gemma 4B (full precision) answers correctly, split by
the position the correct answer is in. On the reading tests it is least accurate when the answer is at A:
Högskoleprovet dev 53.6% at A against 70.8–75.9% at B–D (n = 900), hidden 57.2% (n = 320) and test 2025–26
57.5% (n = 120). Belebele Swedish (76.4% at A, 82.4–84.6% elsewhere) and Belebele English (83.4% at A,
86.4–88.4% elsewhere) use the same 500 questions. MMLU maths (n = 400) goes the other way: 45.8% at A and 46.0%
at B, 34.5% at C and D. Gray line: chance (25%). Sources: `rotation_proof.json` (dev),
`heldout_position.jsonl` (hidden, test), `other_exams/unedited.json`.

**Figure 2 (fig2_edit_effect).** Change in accuracy at each answer position after editor 3's edit
(edited minus unedited, in percentage points). Under each letter: questions that became right / became wrong
at that position. Accuracy at A rises on every test: +9.2 points on dev (83 gained, 0 lost), +8.4 hidden
(27/0), +9.2 test (11/0), +4.2 Belebele Swedish (21/0), +2.4 Belebele English (12/0) and +11.2 maths (45/0).
The price is a small loss at B–D on reading tests (0 to −3.3 points) and a larger one on maths (B −6.0, D
−4.2), where the model already favoured A. Averaged over positions the score barely moves (Belebele Swedish
81.8 → 82.35, English 86.4 → 86.4, maths 40.2 → 39.9). Gray dots: a random change of the same size, which
changes the net count at any position by at most two questions (dev A: 2 gained, 0 lost). The dev set includes papers
the editor practised on; hidden and test are held out and had no random-control run. Sources as Figure 1, plus
`other_exams/editor3.json` and `random.json`.

**Figure 3 (fig3_methods_heldout).** Held-out Högskoleprovet accuracy (LÄS + MEK, options in their original
order) for five ways of answering: the unedited model; the unedited model with a prompt note about answer
positions; the unedited model with option averaging (each option's probability summed over the four
rotations); editor 3's edited model; and the edited model with option averaging. Hidden set (n = 320): 72.5,
71.9, 74.4, 73.8 and 74.4%. Test set, the 2025–26 papers (n = 120): 70.0, 73.3, 75.0, 70.8 and 75.0%. Bars are
95% Wilson score intervals for each score on its own. They overlap heavily, and paired tests on the same
questions also find no difference (p ≥ 0.15). These data show that answer position matters, not which method
scores best. Source: `heldout_position.jsonl`.

**Figure 4 (fig4_letter_picks).** Share of all answers choosing each letter, counted over the four rotations,
so a model with no letter preference would pick each letter 25% of the time (gray line). Unedited Gemma
under-picks A on Belebele Swedish (22.2%) and English (23.1%); editor 3's edit brings A up to 24.1% and 24.8%.
On MMLU maths the unedited model already over-picks A and B (28.9%, 29.5%). The edit pushes A to 39.2% and
cuts B, C and D to 24.3, 18.5 and 18.0%. Swedish other letters: 25.0, 25.6, 27.2% → 24.1, 25.1, 26.8%. English:
25.9, 25.1, 26.0% → 25.4, 24.6, 25.2%. n = 500 questions × 4 = 2,000 answers per Belebele language and
400 × 4 = 1,600 for maths. Source: `other_exams/unedited_with_choices.json`, `editor3_with_choices.json`.
